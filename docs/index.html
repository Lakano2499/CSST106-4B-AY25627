Lab 01 Theory & Report Answers (Hard-Copy Reference)

1. How are digital images digitally represented and manipulated in Computer Vision?

In computer vision, digital images are modeled as multi-dimensional numerical matrices (tensors) of pixel values. Grayscale images are 2D arrays of shape (Height, Width) with values from 0 (black) to 255 (white). Color images are 3D arrays of shape (Height, Width, Channels). Pixel manipulation involves mathematical matrix slicing, spatial transformations, and matrix operations.

2. Why does OpenCV use BGR color channel ordering instead of RGB?

Historically, when OpenCV was first developed in 1999 by Intel, camera sensor manufacturers and video software systems stored pixel bytes in Blue-Green-Red (BGR) order in memory. While modern web browsers and display monitors use Red-Green-Blue (RGB), OpenCV retains BGR for backward compatibility.

3. What are real-life applications of basic image operations?

ROI cropping is used in automated license plate recognition (ALPR) to isolate plates; resizing is vital for neural network preprocessing where inputs must match fixed dimensions (e.g., 640×640 in YOLO); and rotation is foundational in dataset augmentation for computer vision training.

Lab 02 Theory & Report Answers (Hard-Copy Reference)

Explain the differences between the edge maps produced by Sobel and Canny:

1. Sobel Edge Detection: A 1st-order derivative gradient operator that computes horizontal (Sobel X) and vertical (Sobel Y) intensity differences. The resulting magnitude map displays continuous, gradient-shaded edges with varying thickness. Because it lacks thresholding and non-maximum suppression, edges can appear blurry and sensitive to background noise.

2. Canny Edge Detection: A comprehensive 4-stage edge detection pipeline: (1) Gaussian smoothing, (2) Sobel gradient computation, (3) Non-Maximum Suppression (thinning candidate edges to 1-pixel width), and (4) Hysteresis Thresholding using dual thresholds to link strong and weak edge pixels. Consequently, Canny yields clean, 1-pixel thin, closed, and noise-free binary edge contours.

Lab 03 Theory & Report Answers (Hard-Copy Reference)

1. What is histogram equalization and why do we need it?

Histogram equalization is a non-linear contrast enhancement technique that redistributes pixel intensities evenly across the dynamic range (0–255). It is essential in computer vision because underexposed or overexposed images bunch pixel values into narrow intensity clusters, obscuring edges and features required for downstream feature extraction.

2. How does CLAHE differ from Global Histogram Equalization?

Global histogram equalization computes a single Cumulative Distribution Function (CDF) for the entire image, which often over-amplifies background noise in homogeneous regions. In contrast, CLAHE divides the image into contextual local tiles (e.g., 8×8), applies equalization locally, and strictly caps histogram bins at a 'clipLimit' before using bilinear interpolation to blend tile borders seamlessly.

Lab 04 Theory & Report Answers (Hard-Copy Reference)

1. What effect does changing the Hessian threshold have on detected keypoints?

The Hessian threshold acts as a determinant blob-response filter. Increasing the threshold retains only the most prominent, high-contrast corner and blob points (yielding fewer keypoints with higher repeatability). Decreasing the threshold admits weaker responses, increasing the total keypoint count but introducing noisy, less stable points.

2. How does SURF compare with SIFT and ORB?

SIFT uses Difference-of-Gaussians (DoG) and produces 128-dimensional floating-point descriptors; it is highly accurate and scale/rotation invariant but computationally intensive. SURF uses integral images and Haar wavelets with 64-dimensional descriptors, running significantly faster than SIFT. ORB is an unpatented, open-source binary descriptor (256-bit Hamming distance) that executes orders of magnitude faster than both SIFT and SURF.

Lab 05 Theory & Report Answers (Hard-Copy Reference)

1. What does mathematical whitening do, and why is it beneficial before feeding PCA data into an SVM?

When whiten=True is specified in PCA, each projected principal component coordinate is divided by its singular value. Mathematically, this projects the transformed features into an isotropic uncorrelated Gaussian distribution with unit variance. For an RBF-kernel SVM, whitening ensures all principal components exert equal geometric weight in distance computations, preventing dominant components from overpowering subtle diagnostic features.

2. Visual Interpretation of Eigenfaces:

The initial Eigenfaces capture coarse, global illumination and low-frequency structures (e.g., forehead width, overall lighting angle, jawline boundaries). In contrast, higher-order Eigenfaces capture high-frequency localized features (e.g., mouth shape, nose bridge curvature, eye corner details, and hairline transitions).

Lab 06 Theory & Report Answers (Hard-Copy Reference)

What is object detection in computer vision, and how does it differ from image classification?

Image Classification: Takes an entire image as input and outputs a single categorical label indicating what the dominant subject is (e.g., 'dog'), without providing any spatial location.

Object Detection: Solves both classification and spatial localization concurrently. It predicts both 'what' objects are present and 'where' they are located by generating bounding box coordinates [x1, y1, x2, y2] for multiple co-occurring objects across diverse classes in a single forward pass.

Lab 07 Theory & Report Answers (Hard-Copy Reference)

Explain the differences between thresholding, region-based, edge-based, and semantic segmentation with advantages and limitations:

Technique Core Principle Key Advantage Key Limitation
Thresholding Separates pixels based on scalar intensity cutoff (e.g. Otsu bimodal). Extremely fast, minimal computation. Fails under uneven lighting and low contrast.
Region-Based (Watershed) Simulates flooding topological surfaces from markers/distance peaks. Separates touching, overlapping objects cleanly. Prone to over-segmentation without exact markers.
Edge-Based Identifies boundaries via gradient discontinuities (Canny) and groups contours. Preserves exact boundary shapes and perimeters. Sensitive to noise; broken edge gaps prevent closed regions.
Semantic (DeepLabV3) Assigns class labels to every pixel using deep convolutional feature maps. Understands complex real-world multi-class scenes. Computationally heavy, requires pre-trained weights.
