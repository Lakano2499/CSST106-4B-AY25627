Laboratory Activity 6: Segmentation Technique

Objective:
To understand and apply different image segmentation methods — thresholding, region-based, edge-based, and semantic segmentation — and compare their effectiveness on various types of images.
Materials:
Computer with Python and OpenCV, scikit-image, and deep learning libraries (e.g., TensorFlow or PyTorch) installed
Sample images with different features (e.g., simple grayscale with clear objects, complex textures, natural scenes, annotated semantic segmentation datasets like PASCAL VOC or COCO)
A computer or workstation capable of running image processing and deep learning software.
Sample images representing various segmentation challenges (grayscale images, complex textures, natural scenes).
Datasets:
Publicly available and commonly used image datasets for segmentation tasks, such as:
PASCAL VOC Dataset: For semantic segmentation with pixel-level labels.
COCO Dataset: Large-scale object detection and segmentation dataset.
Custom sample images including simple binary images for thresholding practice.
Optionally, additional annotated datasets can be used to evaluate segmentation quality and for semantic segmentation training.
Software:
Python programming environment.
Image processing libraries: OpenCV, scikit-image.
Deep learning frameworks: TensorFlow or PyTorch (for semantic segmentation models).
Pre-trained semantic segmentation models (e.g., DeepLab, U-Net).
Jupyter Notebook or an Integrated Development Environment (IDE) like VSCode for interactive coding and visualization.
Procedure:
Thresholding Segmentation
Load a grayscale image.
Apply global thresholding (e.g., Otsu's method) to segment the image into foreground and background.
Apply adaptive thresholding to handle non-uniform illumination.
Observe and record the segmentation results.
Discuss the advantages and limitations of thresholding (best for simple, high-contrast images).
Region-Based Segmentation
Implement region growing segmentation starting from selected seed points.
Apply watershed algorithm for separating touching objects.
Observe how regions are formed based on pixel similarity criteria.
Discuss challenges in seed selection and over-segmentation.
Edge-Based Segmentation
Apply edge detection operators (e.g., Canny edge detector) to highlight object boundaries.
Use the edges to guide segmentation, for example, by detecting closed contours.
Compare segmentation borders with those from region-based methods.
Discuss sensitivity to noise and edge clarity.
Semantic Segmentation
Use a pre-trained deep learning model (e.g., DeepLab, U-Net) on a complex image dataset.
Perform semantic segmentation to label each pixel with class information.
Visualize the segmented output with labels.
Discuss the benefits of semantic segmentation for detailed scene understanding.
Analysis:
Compare segmentation results qualitatively and quantitatively if ground truth is available (e.g., using metrics like IoU).
Discuss appropriate use cases and limitations for each technique.
Reflect on computational complexity and implementation challenges.

(on an A4 bond paper):
Question Explain the differences between thresholding, region-based, edge-based, and semantic segmentation techniques. Provide one advantage and one limitation for each method.
