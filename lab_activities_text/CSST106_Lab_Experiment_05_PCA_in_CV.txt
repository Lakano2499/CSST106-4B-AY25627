1. Introduction and Theory
In computer vision, raw image data is highly dimensional. A simple 100x100 pixel grayscale image represents a point in a 10,000-dimensional space. Processing data in such high dimensions leads to the "curse of dimensionality," making algorithms computationally expensive and prone to overfitting.
Principal Component Analysis (PCA) is an unsupervised mathematical procedure that uses an orthogonal transformation to convert a set of observations of possibly correlated variables into a set of values of linearly uncorrelated variables called principal components.
When applied to facial images, these principal components represent the statistical variations among the faces in the dataset. Because they look like ghostly faces, they are famously termed "Eigenfaces." Any human face can be approximated as a weighted linear combination of these base Eigenfaces.
