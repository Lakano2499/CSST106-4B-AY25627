Laboratory Activity 3: Edge Detection
Objective:
To understand and implement fundamental edge detection algorithms using Python and OpenCV, specifically the Sobel and Canny edge detectors. The activity aims to teach how to preprocess images, apply edge detection techniques to identify edges, and compare the results to appreciate the differences in edge extraction methods. This will help build foundational skills in image processing and prepare students for further work in computer vision tasks such as object detection, segmentation, and feature extraction

Proceeding to create:
A Python program performing Sobel and Canny edge detection on an input image.
Here is a simple Python program using OpenCV for edge detection (Sobel and Canny) that could be used in a lab activity:

import cv2
import matplotlib.pyplot as plt

def edge_detection(image_path):
    # Load the image in grayscale
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    if img is None:
        print("Error: Image not found or path is incorrect.")
        return
    
    # Apply Gaussian blur to reduce noise
    img_blur = cv2.GaussianBlur(img, (3, 3), 0)
    
    # Sobel edge detection (detects edges along x and y gradient directions)
    sobelx = cv2.Sobel(img_blur, cv2.CV_64F, 1, 0, ksize=3)
    sobely = cv2.Sobel(img_blur, cv2.CV_64F, 0, 1, ksize=3)
    sobel_combined = cv2.magnitude(sobelx, sobely)
    
    # Canny edge detection (detects strong edges using gradient and thresholding)
    edges_canny = cv2.Canny(img_blur, 100, 200)
    
    # Display results using matplotlib
    plt.figure(figsize=(12, 6))
    
    plt.subplot(1, 3, 1)
    plt.imshow(img, cmap='gray')
    plt.title('Original Image')
    plt.axis('off')
    
    plt.subplot(1, 3, 2)
    plt.imshow(sobel_combined, cmap='gray')
    plt.title('Sobel Edge Detection')
    plt.axis('off')
    
    plt.subplot(1, 3, 3)
    plt.imshow(edges_canny, cmap='gray')
    plt.title('Canny Edge Detection')
    plt.axis('off')
    
    plt.show()


if __name__ == "__main__":
    # Replace 'input.jpg' with the path to your image file
    edge_detection('input.jpg')
